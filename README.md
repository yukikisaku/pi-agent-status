# pi-agent-status

Terminal status extensions for the [Pi coding agent](https://pi.dev): a spinner while the agent
works, a completion mark when it finishes, and an AI-generated title so every tab says what it is
actually doing.

Each host gets its own package, so you install exactly one and it configures itself.

| Package | Host | Spinner | Completion mark | Sound | AI title |
| --- | --- | --- | --- | --- | --- |
| [`@yukikisaku/pi-tmux-status`](packages/pi-tmux) | tmux | tmux window name | 🔔 on the window name | bundled sound via `mpv` | ✅ |
| [`@yukikisaku/pi-zed-status`](packages/pi-zed-plugin) | Zed terminal | terminal tab title | Zed's own notification | Zed's own notification | ✅ |
| [`@yukikisaku/pi-orca-status`](packages/pi-orca) | Orca | built into Orca | 🔔 on the tab title | built into Orca | ✅ |
| [`@yukikisaku/pi-herdr-status`](packages/pi-herdr) | Herdr | tab label | 🔔 on the tab label | built into Herdr | ✅ |

Built-in host behaviour is reused where it fits, and each package adds the remaining status cues
without replacing it.

## Install

```bash
pi install npm:@yukikisaku/pi-tmux-status
pi install npm:@yukikisaku/pi-zed-status
pi install npm:@yukikisaku/pi-orca-status
pi install npm:@yukikisaku/pi-herdr-status
```

Every package detects its host from the environment and stays completely inactive elsewhere, so
installing several of them at once is safe.

## Commands

Each package registers `/rename` plus a host-specific interactive settings command:

```
/rename                     regenerate the title from the whole conversation
/rename Fix OAuth callback  set the title explicitly

/pi-tmux                    open the settings menu
```

Use the arrow keys to move, Enter or Space to change a value, and Escape to close the menu. String
and number settings open an input screen. Changes are applied and saved immediately. Any arguments
to the settings command are ignored, so it always opens the same menu.

Settings live in `~/.pi/agent/<package>.json`.

## Title generation

Titles are generated by the model the session is already running on, at low thinking effort, in the
language the user wrote in. Set `naming-model` in the settings menu to use a cheaper model instead,
or clear the field to go back to the session model.

## Development

```bash
npm install
npm run check     # copy core into each package, then typecheck
npm test
```

`packages/core` holds the shared spinner, completion alert, naming, and settings code. It is not
published on its own: `scripts/sync-core.mjs` copies it into each package before typechecking and
before publishing, so every published package is self-contained and has no runtime dependency
beyond Pi itself. Never edit `packages/*/core/` by hand.

```bash
node scripts/publish.mjs 0.1.0 --dry-run
node scripts/publish.mjs 0.1.0
```
